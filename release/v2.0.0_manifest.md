# FSMReasonBench v2.0.0 — release content manifest

High-level inventory of what the v2.0.0 software release is intended to ship.
Not an exhaustive file list.

## Benchmark manifests

- `cohorts/v0.1-expanded-n100/` (C2 / F1 frozen calibration cohort)
- Cohort READMEs and item manifests

## Verifier

- Deterministic witness checkers under `src/fsmreasonbench/verifier/` (and related contract modules)
- Schema contracts under `schema/`

## Evaluation code

- Runners, providers, scoring, failure-stage attribution
- Layered export CLIs (`export_*_empirical_package`, A1 analysis, etc.)

## Archived outputs

- Frozen run trees under `runs/` (raw responses, scores, cell summaries where present in the deposit)
- Analysis package exports under `docs/tosem_empirical_package_v1/`, `docs/a1_constructible_equivalence_v1/`, related docs

## Prompts

- Production prompt templates under `src/fsmreasonbench/runners/`
- Per-item `prompt_metadata` in archived `results.jsonl` where recorded

## Analysis / statistical scripts

- Offline table/figure regeneration scripts (`scripts/reproduce_archived_tables.sh` and legacy wrappers)
- Bootstrap / McNemar export utilities and JSON summaries under `docs/`

## Environment / configuration

- `pyproject.toml` (Python ≥ 3.11)
- Campaign configs under `configs/`
- `environment/` documentation where present

## Documentation

- Top-level `README.md`, `REVIEWER.md`, `docs/`
- Reproducibility notes under `docs/zenodo/`

## Citation / Zenodo metadata

- `CITATION.cff`
- `.zenodo.json`
- `ARTIFACT_VERSION`
- `releases/1.0.0/` (historical) and `releases/2.0.0/` (this version; version DOI pending)
- `CHANGELOG.md`, `RELEASE_NOTES_v2.0.0.md`

## Explicitly out of scope for “full experimental re-run”

- Live frontier/local model regeneration
- Stochastic multi-pass campaigns
